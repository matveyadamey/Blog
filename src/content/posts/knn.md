## Что такое knn?

Это алгоритм машинного обучения, основанный на простом предположении - **гипотезе компактности**. 

> Она говорит - если объекты похожи по признакам, то и значение целевой переменной у них будет похожим.

По народному: *«Скажи мне, кто твой друг, и я скажу, кто ты».*

![Выборка](https://i.postimg.cc/CKFPkrx0/image.png)

Чтобы было понятнее, посмотрим на картинку. На осях расположены значения двух признаков объекта, а цветом выделен его класс. Здесь видно, что объекты расположенные рядом очень похожи друг на друга. Для такой выборки Knn будет работать отлично.

## Как происходит обучение модели?

Этот этап очень прост.

На вход поступают координаты точек и значения целевой переменной.

В коде это выглядит вот так:

```python
def fit(self, points, labels):
 self.points = points
 self.labels = labels

```

Т.е. просто сохраняем нашу выборку. Такой процесс называется **lazy learning**.

## Предсказание

Здесь все более интересно.

В общих чертах алгоритм выглядит так:

- Получаем новый объект
- Вычисляем расстояние от него до всех объектов в выборке (как именно обсудим позже)
- Сортируем объекты по расстоянию
- Берем k ближайших (т.е. с наименьшим расстоянием). K выбирается самостоятельно
- Для классификации берем самый популярный класс из них

Если коротко в виде формулы: 

$$a(x) = \arg \max_{y \in Y} \sum_{i=1}^{k} [y(i) = y]$$

Разберемся с ней по порядку, т.к. эти обозначения еще много где пригодятся.

**$\arg \max_{y \in Y}$** - это означает: выбери такое значение y из множества Y , при котором выражение справа максимально. То есть мы перебираем все возможные классы y и выбираем тот, который даёт наибольшее значение суммы.

**$\sum_{i=1}^{k}$** - это сумма от i=1 до k . То есть мы складываем k слагаемых — по количеству элементов.

**$[y(i)=y]$** - это скобки Айверсона: выражение в квадратных скобках равно 1, если условие верно, и 0, если ложно.

Смысл формулы: берем конкретный класс из множества классов. Считаем сколько из ближайших объектов имеют этот класс. Выбираем такой класс, для которого количество объектов максимально.

Эту формулу надо хорошо осмыслить и понять, т.к. дальше мы к ней еще вернемся.

## Как измерять расстояние?

Для этой цели есть две основные метрики:

- **Евклидово расстояние** 

$$\rho(x, z) = \sqrt{\sum_{j=1}^{d} (x_j - z_j)^2}$$

По сути, просто теорема Пифагора

Вот ее расчет в коде:

```python
def euclidean_distance(self, x, z):
 s = 0
 for i in range(len(x)):
 s += (x[i] - z[i]) ** 2
 return s ** 0.5

```

2. **Манхэттенское расстояние**

Все тоже самое, только квадрат заменили на модуль. Менее чувствительна к выбросам. Движение происходит параллельно осям координат

$$\rho(x, z) = \sum_{j=1}^{d} |x_j - z_j|$$

Расчет в коде:

```python
def manhattan_distance(self, x, z):
 s = 0
 for i in range(len(x)):
 s += abs(x[i] - z[i])
 return s

```

Более подробно про сами метрики и когда какую выбирать расскажу во второй части статьи. Для практических целей такого уровня нам будет достаточно.

## Делаем предсказание

Теперь, когда у нас есть функция расчета расстояния, можно приступать к написанию самого алгоритма.

**Вычисление расстояния до всех объектов**

```python
def calculate_distances_to_all_objects(self, new_object):
 distances = []
 for i in range(len(self.points)):
 distance = self.calculate_distance(new_object, self.points[i])
 distances.append((distance, self.labels[i]))
 return distances

```

Что тут происходит? 

- Создаем массив, в котором будем хранить пары типа расстояние до объекта и его класс
- В цикле заполняем его

**Функция predict**

```python
def predict(self, new_objects):
 predictions = []
 for object in new_objects:
 sorted_points = sorted(self.calculate_distances_to_all_objects(object))
 top_k_labels = sorted_points[:self.k]
 predictions.append(self.mode(top_k_labels))
 return predictions

```

 Что тут происходит? 

- Для каждого нового объекта:
- Получаем объекты и сортируем их по расстоянию
- С помощью среза оставляем первые k объектов
- Передаем их в **функцию mode**
- Возвращаем ее ответ

**Функция mode**

```python
def mode(self, arr:list):
 max_c = -1e9
 arg_max = 0

 for label in set(self.labels):
 c = 0
 for distance, label1 in arr:
 if label == label1:
 c += 1
 if c > max_c:
 max_c = c
 arg_max = label
 return arg_max

```

Для каждого класса в цикле считаем, сколько раз он встречается в наших объектах. 

Если видим, что количество повторений текущего класса выше предыдущего максимума, обновляем его.

Таким образом находим класс, встречающийся чаще всего.

## Взвешенный Knn

На данный момент у нас есть работоспособная версия алгоритма. Одна из проблем, имеющихся у него, это то, что расстояния до объектов учитываются только при ранжировании точек. А при расчете самого популярного класса уже нет. И получается так, что точки расположенные вблизи и точки расположенные вдали имеют одинаковое влияние на ответ. Такого быть конечно же не должно.

В качестве примере приведем вот такую иллюстрацию:

![Необходимость весов в kNN](JSKBHGBMTLYVLPM.jpg)

Можем заметить, что при 5 соседях по логике белая точка должна относится к оранжевому классу, однако точек синего класса больше, и обычный knn сделает выбор в сторону него, не обращая внимания на то, что синие точки находятся дальше оранжевых.

Решить это помогает **добавление весов**, обратно пропорциональных расстоянию, при подсчете классов. Т.е. чем меньше расстояние, тем больше вес этого объекта.

[def] **Ядро**

Функция расчёта веса называется **ядром**. Обозначается как **K**. Такая функция должна обладать лишь двумя свойствами — быть положительной на всей области определения и монотонно не возрастать. Тогда мы и получим нужное нам поведение.

![](https://i.postimg.cc/xT3SxsRd/BDJSEVLVLUGYIRV.jpg)

Т.к. функций, подходящих под описание можно придумать очень много, то и ядер применяется тоже большое количество. Обзор разных ядер и их сравнение будет во 2 части. Так что ждите)

В нашем примере будем использовать **Гауссово ядро:**

$$K(z) = (2\pi)^{-0.5} \exp \left( -\frac{1}{2} z^2 \right)$$

```python
def gauss_kernel(self, x):
 return (2 * np.pi) ** -0.5 * np.exp(-0.5 * x ** 2)

```

> **Важное замечание**:
коэффициент не влияет на результат и его можно не указывать. При расчете можно использовать просто **np.exp(-x ** 2)**

В качестве аргумента этой функции подается собственно расстояние, деленное на особый параметр **h**, называемый **шириной окна**. Этот параметр влияет на гладкость границы и помогает бороться с переобучением (график). Подробнее об этом параметре и как его выбрать во 2 части статьи. Пока лишь скажем, что делается это в основном с помощью кросс-валидации.

Таким образом, получаем новую формулу для подсчета классов (помните, вначале была формула, которую я советовал запомнить)

$$a(x) = \arg \max_{y \in Y} \sum_{i=1}^{k} w_i[y(i) = y]$$

где 

$$w_i = K \left( \frac{\rho(x, x_i)}{h} \right)$$

Ну и наконец получаем финальную версию функции mode:

```python
def mode(self, arr:list):
 max_c = -1e9
 arg_max = 0

 for label in set(self.labels):
 c = 0
 for distance, label1 in arr:
 if label == label1:
 if self.weights == "uniform":
 c += 1
 elif self.weights == "distance":
 weight = self.kernel(distance / self.h) 
 c += weight
 else:
 raise ValueError

 if c > max_c:
 max_c = c
 arg_max = label
 return arg_max

```

## Регрессия

Чтобы переделать классификатор в регрессор, нужно совсем немного. Мы будем вычислять не самый популярный класс, а взвешенно усреднять значения таргета у соседей. 

$$a(x) = \frac{\sum_{i=1}^{k} w_i y(i)}{\sum_{i=1}^{k} w_i}$$

Переделать достаточно лишь одну функцию:

```python
def weighted_prediction(self, arr:list):
 weights_sum = 0
 targets_sum = 0
 for distance, target in arr:
 weight = self.kernel(distance / self.h)
 weights_sum += weight
 targets_sum += weight * target
 return targets_sum / weights_sum

```
