Чтобы опубликовать текст, не нужен админ-интерфейс: достаточно файла `.md`. Имя файла становится адресом страницы. Файл `src/content/posts/how-to.md` открывается как `/posts/how-to/`.

Новый каркас можно создать командой:

```bash
npm run new -- "Название статьи"
```

Она добавит Markdown, папку для картинок и обложку-заглушку.

## Frontmatter

В начале файла — YAML-блок. Обязательны только заголовок и дата:

```markdown
---
title: Как добавить статью
date: 2026-08-17
excerpt: Короткий текст для ленты и поиска.
cover: cover.svg
draft: false
---
```

- `excerpt` — описание в карточках и в поиске. Если не указать, карточка всё равно появится.
- `cover` — обложка. Можно написать имя файла (`cover.svg`) — тогда файл ищется в `public/images/posts/<slug>/`. Можно дать путь от корня сайта: `/images/hero.png`.
- `draft: true` — пост не попадёт в ленту, пока вы его пишете.
- Время чтения считается автоматически.

## Картинки

Положите файлы в `public/images/posts/how-to/` — папка совпадает со slug статьи. В тексте достаточно имени файла. Подпись берётся из `alt`:

```markdown
![Как устроена загрузка: слева текст, справа сетка картинок](cover.svg)
```

![Как устроена загрузка: слева текст, справа сетка картинок](1787046013.png)

Подойдут PNG, JPG, SVG, GIF, WebP. Внешние ссылки тоже работают: `![схема](https://...)`.

## Формулы

Строчные формулы окружайте одним знаком доллара, выносные — двумя. Движок — KaTeX.

Строчная запись: вероятность $P(A \mid B)$ читается как «A при условии B». Выносная:

$$
P(A \mid B) = \frac{P(B \mid A)\,P(A)}{P(B)}
$$

Подробный пример — в статье [Формулы и картинки](../formulas/).

## Заголовки

`##` и `###` собираются в содержание справа. На узком экране содержание складывается в блок «Содержание» под заголовком.

## Определения, теоремы, задачи

Обычный жирный текст **не** становится блоком. Определение помечается явно:

```markdown
[def] **Жорданова клетка**

Квадратная матрица с $\lambda$ на диагонали и единицами над ней.
```

То же самое: `![def] **Жорданова клетка**` или `**Определение:** …`.

Другие блоки — по жирной метке: `Теорема`, `Лемма`, `Утверждение`, `Доказательство`, `Пример`, `Задача`, `Замечание`, `Условие`, `Метод`, `Решение`, `Ответ`.

```markdown
**Теорема о разложении.**
Пространство раскладывается в прямую сумму цепочек.

**Задача 1. (сем)**
**Условие:** Восстановите жордановы клетки.
**Ответ:** $J_1(0)\oplus J_2(0)$.
```

Короткие флаги: `[def]`, `[thm]`, `[lem]`, `[ex]`, `[proof]`, `[note]`. Блок закрывается следующей меткой, `##` или чертой `---`.

### Списки и таблицы

- пункты с маркером
- вложенность работает как обычно

| Поле     | Нужно?     | Зачем                    |
| -------- | ---------- | ------------------------ |
| title    | да         | Заголовок страницы       |
| date     | да         | Сортировка ленты         |
| excerpt  | нет        | Карточка и поиск         |
| cover    | нет        | Превью 16:9              |
| draft    | нет        | Скрыть недописанный пост |

После сохранения файла локальный сервер (`npm run dev`) сразу покажет пост в ленте.
